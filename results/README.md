# ChronoSaga Benchmark Results

This directory contains machine-readable artifacts emitted directly by the `chronosaga benchmark` command. All numbers represent actual measured performance against PostgreSQL; no numbers are synthetic or fabricated.

## Artifacts
- `benchmark_report.json`: Complete benchmark metrics including throughput, percentiles, and recovery times.
- `benchmark_metrics.csv`: Tabular CSV of key performance indicators for automated ingestion.
- `environment_manifest.json`: Hardware, operating system, Go version, and PostgreSQL configuration details.
